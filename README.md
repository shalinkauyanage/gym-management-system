# 🏋️ Gym Management System

A full-stack web-based Gym Management System designed to manage gym members, trainers, workouts, meal plans, memberships, payments, packages, feedback, and administrative operations.

## 📌 Project Overview

The Gym Management System provides a centralized platform for managing the main activities of a fitness center.

It allows administrators and staff to manage gym-related information through a user-friendly web application.

## ✨ Features

- 👤 Member Management
- 🏋️ Trainer Management
- 💪 Workout Management
- 🥗 Meal Plan Management
- 📈 Progress Tracking
- 💳 Membership & Payment Management
- 📦 Package Management
- ⭐ Feedback Management
- 🔐 User Authentication
- 🛠️ Administrative Management

## 🚀 Getting Started

### 1. Clone the Repository

    git clone https://github.com/shalinkauyanage/gym-management-system.git

### 2. Set Up the Project

Place the project inside the WAMP web server directory:

    C:\wamp64\www\

### 3. Set Up the Database

1. Start **WAMP Server**.
2. Open **phpMyAdmin**.
3. Create the required MySQL database.
4. Import the project's SQL database file.
5. Update the database connection settings if required.

### 4. Run the Application

1. Make sure WAMP Server is running.
2. Make sure the MySQL service is running.
3. Place the project inside the `www` directory.
4. Open the application through your local server.

Example:

    http://localhost/gym-management-system/
